# Culina Tool

The modern, ultra-fast recipe manager built for the home cook. Culina Tool features a sleek dashboard, custom RSS discovery feeds, meal planning, and an **AI-powered Instagram & TikTok Importer**.

## Features

- **Personal Recipe Collection**: Beautiful grid interface to store your recipes.
- **Meal Planner**: Drag-and-drop or select recipes to plan your week (Monday - Sunday).
- **Discover Feed**: Real-time RSS feeds to pull in recipes from your favorite food blogs.
- **Magic AI Importer**: Paste messy Instagram or TikTok captions, and our AI perfectly formats the ingredients, prep time, and steps!
- **Admin Dashboard**: Manage users and invite links instantly.
- **Dark Mode**: Beautiful OLED dark mode built-in.

## Installation

### Windows
1. Make sure you have [Node.js](https://nodejs.org/) and [Git](https://git-scm.com/) installed.
2. Download the `download.bat` script, or run:
```bat
git clone https://github.com/JaxonDevs/culina-tool.git
cd culina-tool
install.bat
```
3. Follow the prompts to enter your License Key and optional Google Gemini API key.
4. Run `start.bat` to launch the server!

### Linux / macOS
1. Make sure you have `node`, `npm`, and `git` installed.
2. Clone and install:
```bash
git clone https://github.com/JaxonDevs/culina-tool.git
cd culina-tool
chmod +x install.sh start.sh
./install.sh
```
3. Follow the prompts.
4. Run `./start.sh` and visit `http://localhost:4000` in your browser.
